## How to run

Please follow the below instructions to run this project in your machine:

1. Run npm install

2. Then rename the .env.example file to ".env" and change values as per your need

3. Finally run the application in development using below command -

   ```sh
   npm start
   ```
   or
   You can run it in production mode by -
   ```sh
   npm run prod
   ```

   Open [http://localhost:5000](http://localhost:5000) with your browser to see the result.
